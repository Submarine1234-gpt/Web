黑体辐射实验

黑体是一种能完全吸收所有电磁辐射的理想物体。实验中通常用带小孔的空腔（如高温炉）来近似——辐射进入空腔后在腔壁反复反射、吸收，几乎无法逃出。

实验内容： 将空腔加热至温度 TTT，测量小孔辐射在不同频率 ν\nuν 下的能量密度 u(ν,T)u(\nu,T)u(ν,T)，即确定给定温度下各频率辐射的能量分布。

经典理论的失败（紫外灾难）

经典物理将腔内电磁场视为大量不同频率的谐振子（驻波模式）。根据经典统计力学的能均分定理，每个模式的平均能量为 kTkTkT，与频率无关。

那么，频率在 ν∼ν+dν\nu \sim \nu + d\nuν∼ν+dν 范围内，空腔里能容纳多少种驻波？这个数量称为模式密度 g(ν)g(\nu)g(ν)。

直觉理解： 空腔像一根吉他弦——弦的长度固定，只有特定波长的波能稳定存在（驻波）。频率越高（波长越短），能容纳的驻波模式越多。推广到三维空腔后，模式数随频率增加得更快。

爱因斯坦在普朗克的基础上更进一步：普朗克仅认为振子的能量是量子化的，而爱因斯坦提出光本身由一份份粒子（光子）组成，每个光子携带能量 E=hνE = h\nuE=hν。

注意

为何此处使用完整的复指数，而非像经典波那样取实部？

这是从经典物理到量子力学的关键转折。若仅使用实部 cos⁡\coscos：

Ψ=Acos⁡(kx−ωt)⟹∂Ψ∂t=Aωsin⁡(kx−ωt)\Psi = A\cos(kx - \omega t) \quad\Longrightarrow\quad \frac{\partial\Psi}{\partial t} = A\omega\sin(kx - \omega t) Ψ=Acos(kx−ωt)⟹∂t∂Ψ​=Aωsin(kx−ωt)

求导后 cos⁡\coscos 变为 sin⁡\sinsin，结果无法用 Ψ\PsiΨ 自身表达，推导无法继续。

而使用完整的复指数：

Ψ=Aei(kx−ωt)⟹∂Ψ∂t=−iω Ψ\Psi = Ae^{i(kx-\omega t)} \quad\Longrightarrow\quad \frac{\partial\Psi}{\partial t} = -i\omega\,\Psi Ψ=Aei(kx−ωt)⟹∂t∂Ψ​=−iωΨ

求导后仍为 Ψ\PsiΨ 的常数倍。唯有保留完整的复波函数，才能建立"导数正比于自身"的关系，进而将 ω\omegaω、kkk 转化为能量、动量算符。

经典波中的复指数是计算工具（最终取实部）；量子波函数中的复数是物理本质（不取实部，方程才成立）。

重要

为什么对 xxx 求导得到动量，对 ttt 求导得到能量？

回顾平面波 Ψ=Aei(kx−ωt)\Psi = Ae^{i(kx - \omega t)}Ψ=Aei(kx−ωt)，它包含两种振荡：

  • 空间振荡由 eikxe^{ikx}eikx 描述，振荡快慢由 kkk 决定 → 而德布罗意关系 p=ℏkp = \hbar kp=ℏk 告诉我们 kkk 编码的就是动量
  • 时间振荡由 e−iωte^{-i\omega t}e−iωt 描述，振荡快慢由 ω\omegaω 决定 → 而普朗克关系 E=ℏωE = \hbar\omegaE=ℏω 告诉我们 ω\omegaω 编码的就是能量

对 xxx 求导会从指数中"提取"出 ikikik，乘以 −iℏ-i\hbar−iℏ 后恰好得到 ℏk=p\hbar k = pℏk=p；对 ttt 求导会"提取"出 −iω-i\omega−iω，乘以 iℏi\hbariℏ 后恰好得到 ℏω=E\hbar\omega = Eℏω=E。

求导的本质就是从波函数中读取它所编码的物理量。

后续完善

薛定谔方程建立后，仍需回答一个根本问题：波函数 Ψ\PsiΨ 的物理意义是什么？

玻恩的概率诠释（1926）

玻恩（Max Born） 提出：波函数 Ψ\PsiΨ 本身不直接对应可观测量，但其模方 ∣Ψ∣2|\Psi|^{2}∣Ψ∣2 代表粒子在该处出现的概率密度。

Ψ\PsiΨ 为何不直接可观测？
Ψ\PsiΨ 是复数（含虚部），而所有物理测量结果必须是实数，复数无法直接对应实验观测。

注意

经典波与量子波函数的本质区别：

  • 经典波中，复指数仅为计算工具，物理上的波是实数，最终通过 Re[ ]\mathrm{Re}[\,]Re[] 取实部还原。
  • 量子波函数中，薛定谔方程本身包含虚数单位 iii（iℏ∂∂tΨ=H^Ψi\hbar\dfrac{\partial}{\partial t}\Psi = \hat{H}\Psiiℏ∂t∂​Ψ=H^Ψ），这要求 Ψ\PsiΨ 必须是复数。若强行取实部，方程将不成立。

因此，经典物理中 eiθe^{i\theta}eiθ 是计算捷径；量子力学中 Ψ\PsiΨ 的复数性是物理本质。

∣Ψ∣2|\Psi|^{2}∣Ψ∣2 为何具有物理意义？
模方运算 ∣Ψ∣2=Ψ∗Ψ|\Psi|^{2} = \Psi^{*}\Psi∣Ψ∣2=Ψ∗Ψ（Ψ∗\Psi^{*}Ψ∗ 为复共轭）消除了虚部，结果必为实数且非负，恰好满足概率密度的数学要求。

提示

类比经典光学： 光的电场 EEE 可正可负，不直接代表亮度；而光强 I∝∣E∣2I \propto |E|^{2}I∝∣E∣2 为实数且非负，代表能量密度。Ψ\PsiΨ 与 ∣Ψ∣2|\Psi|^{2}∣Ψ∣2 的关系与此类似。

P(x,t)=∣Ψ(x,t)∣2=Ψ∗ΨP(x,t) = |\Psi(x,t)|^{2} = \Psi^{*}\Psi P(x,t)=∣Ψ(x,t)∣2=Ψ∗Ψ

波函数须满足归一化条件（粒子必定存在于空间某处）：

∫−∞+∞∣Ψ(x,t)∣2 dx=1\int_{-\infty}^{+\infty} |\Psi(x,t)|^{2}\,dx = 1 ∫−∞+∞​∣Ψ(x,t)∣2dx=1

重要

量子力学的预言本质上是概率性的——无法精确预言粒子的位置，只能给出其在各处出现的概率分布。实验发现粒子具有波动行为 → 薛定谔构造方程描述这种波 → 方程的数学结构要求波函数必须是复数 → 复数波函数不可直接观测 → 通过 ∣Ψ∣2|\Psi|^{2}∣Ψ∣2 与实验建立联系。

海森堡不确定性原理（1927）

海森堡（Heisenberg） 证明，粒子的位置 xxx 与动量 ppp 不可能同时被精确确定：

Δx⋅Δp≥ℏ2\Delta x \cdot \Delta p \geq \frac{\hbar}{2} Δx⋅Δp≥2ℏ​

这并非测量仪器的精度限制，而是自然界的根本约束，是波粒二象性的必然结果。

哥本哈根诠释（玻尔，1927）

玻尔（Niels Bohr） 将上述成果综合为哥本哈根诠释，核心要点：

  1. 波函数是完备描述：Ψ\PsiΨ 包含体系的全部信息
  2. 互补原理：波动性与粒子性互补，不会在同一实验中同时显现
  3. 测量导致坍缩：测量前粒子处于多种状态的叠加态，测量瞬间波函数坍缩为确定状态

提示

至此，量子力学的基本框架建立完毕：薛定谔方程描述波函数的时间演化，玻恩诠释赋予波函数概率意义，不确定性原理规定了可知的极限，哥本哈根诠释提供了整体理论框架。
