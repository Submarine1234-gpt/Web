# 图标
1. vuepress的图标库默认应该是Font Awesome 6 Solid，任意前缀都会被修改成prefix: "fa6-solid:"。当然,翻到theme.ts中就可以改，只是懒了。
其实我对图标库没啥概念，没有纸面的图标，我敲名字根本不知道对应的图案，就算知道图案也不知道名字。好在作者推荐了 [Iconify 图标网站](https://icon-sets.iconify.design)，只要搜索喜欢的图标，点击复制全名就可以正常用了。
```bash
icon: mdi:router-wireless
icon: ri:computer-line
```
# 超链接
写法有好几种，我还是喜欢html形式，写得熟悉。
```bash
<a href="https://example.com">点我</a>
[点我](https://example.com)
```
